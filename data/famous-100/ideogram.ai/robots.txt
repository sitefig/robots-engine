# Default crawler policy.
# Allow the marketing surface (everything served by ideogram-ai/website).
# Disallow app surfaces owned by ideogram-ai/ui:
#   /api/  — REST endpoints. Do not Allow /api/learn or /api/pricing; those
#            marketing dups were retired. Top-level /api-* 301s in nginx.
#   /g/    — generation permalinks (too many, low search value; social-bot
#            allow rules above carve out the unfurling case)
#   /t/    — gallery / feed / explore
#   /u/    — user profile pages
# Query-string copies of app entry points: website CTAs (src/lib/cta.ts) and
# developer.ideogram.ai links (/platform, /platform/api-keys) add sign-up
# attribution (?intent=&source=) and plan choices to these URLs, and each copy
# is an app shell with no canonical. The bare paths stay crawlable.
# Googlebot reads only its own group above, so Google Search is unchanged
# (Googlebot-Image and Applebot follow that group too). Other Google crawlers,
# such as GoogleOther and Storebot-Google, read this group. Do not copy these
# lines into the Googlebot group.
